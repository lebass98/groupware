Firestore 초기 데이터 시딩

data/firebase-seed.json의 마스터 데이터를 Firestore로 일괄 업로드합니다.

실행 전 확인하십시오. 아래 순서를 건너뛰면 permission-denied로 실패합니다.
  1. 터미널에서 npm run verify:seed 통과
  2. Firebase 콘솔 > Firestore > 규칙 탭에 firestore.rules 게시
  3. Firestore 데이터 탭에 admins/{내 UID} 문서 생성
시딩은 같은 문서 ID를 덮어씁니다. 기존 데이터를 수정했다면 그 변경분은 사라집니다.
