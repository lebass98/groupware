# WnC 그룹웨어 Git 워크플로우 & 작업 내역 자동화 가이드

## 1. 한글 커밋 메시지 표준 컨벤션 (의무화)

모든 커밋 메시지는 **반드시 명확한 한글(한국어)**로 작성합니다. (영문 커밋 메시지 금지)

### 커밋 접두어 컨벤션
- `기능: [기능 설명]` : 신규 기능 추가 또는 주요 비즈니스 로직 구현
  - 예: `기능: 주소록 예정 뱃지 금일(오늘) 날짜 실시간 캘린더 연동 및 동기화`
- `수정: [수정 내용]` : 버그 픽스, 오류 수정, 동작 이상 개선
  - 예: `수정: 공지사항 상세 페이지 SVG 아이콘 크기 및 레이아웃 안정화`
- `스타일: [스타일/UX 변경]` : UI 디자인 변경, 아이콘 교체, 레이아웃 정렬
  - 예: `스타일: 하단 독 메뉴 공지사항 아이콘 알림 벨(notifications) SVG로 교체`
- `빌드: [빌드/패키징]` : APK 빌드, 의존성 설치, 설정 파일 변경
  - 예: `빌드: 안드로이드 릴리즈 APK 패키징 및 빌드 검증 완료`
- `문서: [문서 업데이트]` : README.md, 스킬 파일 등 문서화 작업

---

## 2. README.md 작업 내역 요약 자동화 규칙

코드 작업 완료 시, `README.md` 하단의 `📅 작업 내역 (Work History)` 섹션에 해당 일자(YYYY-MM-DD)별로 **장황한 설명 없이 1줄 핵심 요약 불릿**을 자동 기록합니다.

### 작성 형식 예시
```markdown
### 2026-08-21
- **주소록 예정 일정 뱃지 금일(오늘) 날짜 실시간 연동 및 동기화**: 주소록 목록 및 상세 화면의 예정 뱃지가 금일 캘린더 일정을 동적으로 정확히 반영하도록 갱신.
- **안드로이드 릴리즈 APK 패키징 및 빌드 검증 완료**: Java 17 및 Android Gradle 8.x 환경에서 JS 번들링 및 릴리즈 빌드(assembleRelease) 오류 전수 점검 및 최적화 APK 생성 완료.
```

## 3. Git 동기화 자동화 파이프라인
 
모든 변경 사항 완료 전후 및 Git 풀(`git pull`) 시 `._*` 임시 메타데이터 파일을 전량 삭제한 뒤 아래 순서로 저장소 상태를 동기화합니다.
 
```bash
# 1. macOS 메타데이터 및 AppleDouble 파일 즉시 삭제
find . -name "._*" -delete
dot_clean . 2>/dev/null || true

# 2. Git 스테이징 및 커밋/푸시/풀
git add -A
git commit -m "접두어: 명확한 한글 커밋 메시지"
git push origin main
git pull origin main

# 3. 풀다운(동기화) 직후 유입/생성된 ._* 파일 전량 재삭제
find . -name "._*" -delete
dot_clean . 2>/dev/null || true
```
